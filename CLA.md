## How to sign

You do not send this file anywhere. Open a pull request, and a bot will comment
asking you to sign. Reply on the pull request with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Your signature is recorded, with your GitHub username and the commit it applied
to, in the `cla-signatures` branch of this repository. Signing once covers all
your future contributions; you will not be asked again.

Trivial changes are exempt. If the bot asks and you think it should not have,
say so on the pull request.
