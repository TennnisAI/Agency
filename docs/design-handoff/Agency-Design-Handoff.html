Design Handoff · v0.3.1 · 2026-06-19

Agency

Local desktop app for running multiple terminal coding agents in parallel — each isolated in its own git worktree — with live terminals, a full git review surface, and an approve→merge flow. This document hands off the high-fidelity UI mockups to engineering and specifies the design system, screens, components, states, and interactions needed to build them.

Tauri + Rust core + web UI Catppuccin Mocha Geist · JetBrains Mono Cross-platform · macOS / Windows / Linux

02

Product & architecture context

Agency is a Tauri application: a Rust core owns all state, process management, and git operations; the web UI (React + xterm.js) is the renderer. The mockups map to these UI surfaces:

Project sidebarMulti-project dashboard; foldable tree of projects → their agent runs (worktrees). Task boardPer-project cards / list of agent runs with live status dots — the Agents view (Grid & Focus). Live terminalxterm.js pane bound to the selected task's PTY. Watch, interject, send feedback. Git panelPer-worktree source control: file tree + diff + stage/commit/push + approve/discard. SettingsAgent profiles (Claude Code, Pi, Hermes), model providers (Anthropic, LM Studio).

Each agent run lives on branch agent/<task-id> in a worktree under <repo>/.agency/worktrees/<task-id>, branched off a chosen base (default main).

03

Screens & information architecture

Agents · Grid

Tiling grid of agent terminals — every run visible at once. Each tile = status dot · title · agent badge · branch · diff stat · live terminal preview (fades at the bottom) · status + contextual action footer. Click a tile header to open it in Focus.

Agents · Focus

One large terminal for the selected run, with an agent list rail on the left. Header carries title, agent, branch, status, and Stop / Send feedback / Approve actions. An input line at the bottom represents PTY interjection.

Source Control

VSCode-style: commit message box, staged vs. unstaged file lists with per-file stage/unstage, history graph, and a unified diff viewer with per-hunk Stage buttons. Selecting a file swaps the diff.

Settings

Agent Profiles (command / args / env per agent), Model Providers (Anthropic API key, LM Studio base URL with detect), and General (default base branch, worktree location, theme).

New Task (modal)

Prompt, project, base branch, agent profile, and model provider — with a live preview of the worktree path and agent/<id> branch that will be created.

Merge resolver (modal)

The approve→merge flow: checkout → rebase → resolve → summary timeline, the resolver agent's terminal, per-conflict resolution status, and a plain-language summary. Footer: Discard / Keep worktree / Confirm merge.

v2 additions

  • Git Review side-panel in the Agents view (toggle in the header) — branch, diff stat, commit box, Commit/Push, staged & changed files, and "Open in Source Control →". Works in both Grid and Focus.
  • Collapsible sidebar via the left-panel icon in the title bar; main content reflows to full width.
  • Collapsible focus agent-list (« / ») that tucks to a slim rail so the terminal expands.
  • Foldable project tree — expand a project to reveal its agents/worktrees; clicking one opens that agent in Focus.
  • Project-switchable git history — A/W/M/D pills in the History section swap which project's commit log is shown.

Spacing rhythm is tight (power-user density): 6–8px inside controls, 12–18px inside cards/panels, 14px grid gaps. Borders are a single hairline #25253a; cards sit on #181825 over a #1e1e2e canvas. 08

Interactions & states

  • Agent status heuristics — Running / Awaiting input / Idle (review) / Exited(code) / Crashed. Ambiguous resolves to "Idle — review needed"; never a false "done." Each drives dot color, footer action, and tile border.
  • Title bar is custom (borderless, consistent across OSes): left-panel toggle · app mark · global search (⌘K) · window controls. Close glyph hovers red.
  • Collapse — left-panel icon hides the whole project sidebar; « / » collapses the focus agent rail to a 38px labeled stub. Both reflow neighbors.
  • Project tree — chevron expands a project to its agent runs; clicking an agent navigates to Focus for that run.
  • Git Review panel — toggled from the Agents header; scoped to the focused agent's worktree. "Open in Source Control →" deep-links to the full diff.
  • History — A/W/M/D pills switch the project whose commit log + ahead/behind is displayed.
  • Destructive ops (discard branch, remove worktree, force-push) must be confirmed — surfaced in red.
  • Keyboard — status bar advertises ⌘N new · ⌘G source · ⌘↵ approve; wire these plus ⌘K search.
09

Notes for implementation

  • Terminals are xterm.js bound to each task's PTY (the mockups use static text). Match the token palette above for the agents' ANSI theme.
  • Diffs render add/del/hunk styling as specified; the Stage hunk / Stage all affordances map to the core's stage-by-hunk service.
  • Selection, active nav, collapse, and history-project are simple view state; everything authoritative (projects, tasks, worktrees, diffs) comes from the Rust core.
  • Fonts: Geist + JetBrains Mono. Bundle them with the app for offline use rather than relying on a CDN.
  • Build color + spacing as tokens (the Theme setting implies palette swapping).
  • The mockups carry no first-party telemetry/analytics messaging in the UI by design — keep the chrome free of it.
To view the mockups: open Agency v2.dc.html in a modern browser with support.js in the same folder. Everything is clickable — switch Grid/Focus, open Source Control, expand a project, toggle the panels, and open the New task / Merge modals.
