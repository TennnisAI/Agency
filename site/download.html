Packages for Linux

Linux

Every package comes for x86_64 and arm64, and uname -m says which you have. Install from a terminal, in the folder you downloaded to. The commands use the x86_64 names; on arm64, use the name of the file you downloaded.

.deb for arm64

Use apt rather than opening the file in Ubuntu's App Center, which can stall at "Installing" on a downloaded package.

Arch, and any other distribution

AppImage for x86_64

Agency_0.2.1_amd64.AppImage · 89.6 MB

AppImage for arm64

Agency_0.2.1_aarch64.AppImage · 87.2 MB

chmod +x Agency_0.2.1_amd64.AppImage
./Agency_0.2.1_amd64.AppImage

The AppImage carries its own libraries and needs only FUSE from the system. If it stops with a libfuse error, install your distribution's FUSE package, or run it with APPIMAGE_EXTRACT_AND_RUN=1 set. It does not add itself to your application menu, and there is no AUR package yet.

apt and dnf fetch WebKitGTK and the other libraries Agency needs, and a newer package installs over an older one the same way. The packages are not signed. Two things are weaker than on macOS: the tray shows the running-agent count in its tooltip rather than beside the icon, and clicking a notification does not open the run it was about.

Requirements

  • macOS 11 or later, on Apple Silicon. There is no Intel or universal build.
  • Or Linux with glibc 2.34 or later, on x86_64 or arm64: Ubuntu 22.04, Debian 12 and anything newer, and current Fedora and Arch.
  • Git. If you do not have it, Agency offers to install it: through Homebrew or the Command Line Tools on macOS, and through your distribution's package manager on Linux.
  • No account, and nothing to sign up for.
  • At least one agent CLI. Agency detects what is on your PATH and offers to install a missing one. Most install through npm, so those need Node.
  • gh, optional, and only for the GitHub import and pull request flows.
  • uv and graphify, optional, and only if you turn on the per-project knowledge graph. Agency shows you the install script before it runs anything.

Other platforms

Windows is planned. There is no build and no date yet.

Install

  1. On macOS, open the DMG and drag Agency to Applications. On Linux, run the command for your distribution above.
  2. Launch it and pick your default agent.
  3. Add a project by pointing Agency at a local git repo.

Agency is pre-1.0 and in beta. If macOS says the app is damaged, you have an unsigned local build rather than a release DMG.
